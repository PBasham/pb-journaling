# PB Notes

A local-first notes app organized as **Collections > Books > Pages**, plus loose notes. Search, PIN and biometric locks, encrypted backups, and light, dark and accent themes. Built with Expo 58, Expo Router, SQLite (Drizzle) and the TenTap rich text editor.

```bash
npm install
npm run dev          # development build (expo-dev-client)
npm test             # unit tests (sql.js in-memory SQLite)
npm run e2e:build && npm run e2e   # browser tests
```

See `PLAN.md` for status and `CLAUDE.md` for project rules.
